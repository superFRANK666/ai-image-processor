# Third-Party Notices

This repository no longer vendors third-party model source code.

SAM2 is used through the `transformers` package and downloaded model weights under `models/`.
Model weights are not tracked in Git.

Optional API-backed LLM providers such as OpenAI, Anthropic, or OpenAI-compatible gateways are external services. When enabling them, review the provider's terms, data handling policy, and model license or service agreement.

When publishing or redistributing this project:

1. Review upstream license terms for external packages and downloaded model weights.
2. Ensure your distribution complies with all applicable third-party licenses in addition to this repository's MIT license.
